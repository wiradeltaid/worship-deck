# WorshipDeck

> Локальный программный комплекс для церковных богослужений и презентаций (local-first): автоматическое преобразование расписания службы в готовые слайды: генерация автономных презентаций PowerPoint (.pptx) со встроенными шрифтами, двухэкранная консоль оператора для экрана общины и дистанционное управление со смартфона по локальному Wi-Fi.

## Решаемые задачи

Ручная подготовка слайдов к богослужению отнимает от 2 до 4 часов каждую неделю, большая часть которых тратится на повторный набор текстов гимнов. Неожиданная замена псалма вынуждает переделывать презентацию заново, а технический навык зачастую сосредоточен в руках одного добровольца.

WorshipDeck принимает готовое расписание службы из чата или формы и автоматически формирует аккуратные слайды.

```text
текст расписания  ->  анализ службы  ->  план слайдов  ->  +->  автономный PowerPoint (.pptx)
                                                           +->  полноэкранный веб-показ
                                                           +->  консоль оператора + экран общины
```

Тексты гимнов загружаются по номеру из локальной базы данных. Макеты настраиваются в браузере через реестр SQLite. После скачивания файла PowerPoint интернет-соединение не требуется, что обеспечивает стабильное проведение служения даже при сетевых сбоях.

## Основные возможности

- **Автоматический разбор расписания:** Вставка текста в веб-форму. Нераспознанные строки отображаются прозрачно и никогда не удаляются без предупреждения. (Прием через вебхук будет доступен в следующем релизе.)
- **Разделение на куплеты и повтор припева:** Гимны по номеру разделяются на заглавный слайд, куплеты и повторяющиеся припевы для удобства пения общиной.
- **Редактируемые макеты слайдов:** Управление макетами в реестре SQLite с помощью редактора на холсте в браузере. Перемещение элементов, изменение текста и оформления, импорт макетов из PowerPoint. Набор из 38 демонстрационных макетов доступен через начальную инициализацию.
- **Один макет для четырех выводов:** Единый набор данных управляет файлами PPTX, веб-слайд-шоу, экраном общины и предпросмотром в формате 16:9.
- **Режим ведущего для двух мониторов:** Текущий и следующий слайды, лента миниатюр, список служения, сетка быстрого перехода и независимое окно для экрана общины.
- **Затемнение экрана (Blank Screen):** Мгновенное затемнение экрана общины без потери текущей позиции в презентации (`B`).
- **Эффекты переходов:** Срез, затухание, растворение и сдвиг, одинаково работающие в браузере и в PowerPoint.
- **Мгновенный вывод библейских стихов:** Отображение стихов Библии (KJV) на экране общины во время проповеди и быстрое скрытие.
- **Объявления общины:** Управление афишами и объявлениями из локального хранилища или разрешенных источников.
- **Шрифты без подключения к сети:** 41 локально упакованное семейство шрифтов, а также поддержка внедрения пользовательских шрифтов по стандарту ECMA-376 в PowerPoint.
- **Разграничение прав доступа:** Раздельные учетные записи администратора и оператора, ограничение частоты запросов и отзыв сессий.
- **Динамический макет формы и разбор:** Настройка предопределенных полей с пользовательскими регулярными выражениями и организация групп формы прямо в панели администратора.
- **Медиатека:** Переиспользуемый набор фоновых изображений и афиш, не привязанный к конкретному макету.
- **Ручная синхронизация между устройствами (экспериментально):** Отправляйте и получайте Служения, записи Song Set, фоны и объявления между двумя экземплярами WorshipDeck в одной локальной сети по запросу оператора. Без облака, без фоновой синхронизации. Проверено на одном хосте; синхронизация между разными машинами остается экспериментальной.

## Системные требования

- **Серверная установка (Рекомендуется):** Linux (протестировано на Ubuntu), Windows 10/11 или POSIX-система с Go 1.24+ и Node.js 22.12+. Разработано на React 19. Используется встроенная SQLite, отдельный сервер баз данных не требуется.
- **Десктопное приложение Windows (Экспериментально):** Windows 10/11 64-бит.
- **macOS:** Официально не тестировалось.

## Установка

### Локальный сервер (Рекомендуется)

Запуск WorshipDeck в качестве локального сервера является основной и рекомендуемой моделью развертывания:

```bash
git clone https://github.com/wiradeltaid/worship-deck.git
cd worship-deck
npm install
npm run setup
npm run dev
```

`npm run setup` создает файл `.env` со сгенерированными ключами, инициализирует базу данных SQLite и выводит пароль для учетной записи `admin`. `npm run dev` запускает сервер Go API на <http://localhost:3000> и веб-приложение React на <http://localhost:5173>. Войдите под учетной записью `admin`. Для рабочей эксплуатации на одном порту выполните `npm run spa:build && npm start` и откройте порт 3000.

Ознакомьтесь с [`.constitution/project/private-data.md`](.constitution/project/private-data.md) перед вводом данных вашей общины.

### Установщик для Windows (Экспериментально)

Загрузите файл `WorshipDeck-0.1.0-x64-setup.exe` и `SHA256SUMS` с [официальной страницы релизов](https://github.com/wiradeltaid/worship-deck/releases) и запустите мастер установки.

Проверьте файл перед запуском: сравните вычисленный хэш SHA-256 со значением в `SHA256SUMS`.

> **Примечание по Windows SmartScreen:** Поскольку сборка пока не подписана коммерческим сертификатом, Windows SmartScreen может показать предупреждение. Нажмите **Подробнее**, затем **Выполнить в любом случае**.

### Создание службы

Перейдите в **Services -> New**. Вставьте текст расписания в текстовое поле:

```text
SABBATH, MARCH 14, 2026

BIBLE TALK (09.30-10.50 / 80 min)
>> welcome remarks: Mrs. Lestari
Song Leader : Ms. Ayu
[  ] Opening song : SDAH #159 The Old Rugged Cross
Memory Verse & Opening Prayer : Mr. Bagas
Closing Prayer : Mr. Damar (1m)

DIVINE SERVICE (10.50-12.05 / 75 min)
Song Leader : Ms. Kirana
[  ] Opening Song : SDAH #83 O Worship the King
Intercessory Prayer: Mr. Farid (5m)
Sermon : Pr. Andi Hartono "Working Out" (45m)
[  ] Closing Song : SDAH #249 Praise Him! Praise Him!
```

Нажмите **Baca susunan acara** (или **Parse** в английском интерфейсе). Роли, время и номера гимнов автоматически распределятся по форме, а тексты гимнов будут загружены из локальной базы данных. Нераспознанные строки отображаются для проверки.

Добавьте афишу проповеди и фотографии, затем сохраните службу.

### Проведение презентации

На странице службы:

- **Скачать PPTX:** Автономная презентация PowerPoint на случай непредвиденных технических сбоев.
- **Презентация:** Консоль оператора с предпросмотром слайдов, лентой миниатюр и быстрым переходом.
- **Открыть экран общины:** Отдельное окно без элементов управления для вывода на второй монитор. Клавиша `B` для затемнения экрана.

### Дополнительные возможности

**Поиск библейских текстов:** Выводите стихи Библии KJV на экран общины из `data/en/bible-translation/kjv.json`.

**Интеграция с ботами:** Прием расписания через вебхук появится в будущем релизе.

### Устранение неполадок

**`Missing song book corpus`:** Файл `data/song-book/sdah.json` отсутствует. Восстановите его через Git: `git checkout -- data/song-book/sdah.json` и запустите `npm run corpus:verify`.

**Сброс пароля:** Выполните `npm run auth:set-password -- admin` для установки нового пароля. Команда `npm run auth:unlock -- --list` снимает блокировку попыток входа.

**Не отображаются изображения:** Внешние изображения должны соответствовать правилам безопасности URL. Локальная загрузка на сервер работает всегда надежно.

## Настройка для вашей общины

Стандартная установка запускается с чистым реестром, готовым для ваших собственных материалов:

1. **Макеты слайдов:** Войдите под администратором и откройте `/admin/artifacts`. Макеты можно создавать на холсте или импортировать из PowerPoint. 38 демонстрационных макетов можно загрузить командой `npm run seed:demo`.
2. **Локальное переопределение:** Чтобы хранить данные общины вне Git, поместите файл в `data/local/default-registry.json`. Этот путь игнорируется Git. См. [`.constitution/project/private-data.md`](.constitution/project/private-data.md).

## Включенные текстовые корпуса

В поставку входят два проверенных текстовых корпуса:

| Файл | Содержимое | При запуске |
| --- | --- | --- |
| `data/song-book/sdah.json` | 695 гимнов Seventh-day Adventist Hymnal | названия и тексты читаются из файла |
| `data/en/bible-translation/kjv.json` | 66 книг, 1189 глав, 31102 стиха Библии KJV | синхронизируются из локального файла (~130 до 150 мс) |

Запустите `npm run corpus:verify` для проверки целостности.

Информация об авторских правах и контакты для обращений приведены в [ATTRIBUTIONS.md](ATTRIBUTIONS.md).

## Развертывание

Скомпилируйте Go API и SPA, затем запустите `./api` (или `npm start`) на сервере с Node 22 в `PATH`. См. [`.constitution/project/deployment.md`](.constitution/project/deployment.md).
