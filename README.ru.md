# WorshipDeck

> Локальный программный комплекс для церковных богослужений и презентаций (local-first): автоматическое преобразование расписания службы в готовые слайды — генерация автономных презентаций PowerPoint (.pptx) с внедренными шрифтами, двухэкранная консоль оператора проектора и дистанционное управление со смартфона по локальному Wi-Fi.

## Решаемые задачи

Ручная подготовка слайдов к богослужению отнимает от 2 до 4 часов каждую неделю, большая часть которых тратится на повторный набор текстов гимнов. Неожиданная замена псалма вынуждает переделывать презентацию заново, а технический навык зачастую сосредоточен в руках одного добровольца.

WorshipDeck принимает готовое расписание службы (вставленный текст или сообщение от чат-бота) и автоматически формирует аккуратные слайды.

```text
текст расписания  →  анализ службы  →  план слайдов  →  ┬→  автономный PowerPoint (.pptx)
                                                        ├→  полноэкранный веб-показ
                                                        └→  консоль оператора + проектор
```

Тексты гимнов загружаются по номеру из локальной базы данных. Оформление шаблонов настраивается в браузере через реестр SQLite. После скачивания файла PowerPoint интернет-соединение не требуется — служение пройдет стабильно даже при сетевых сбоях в молитвенном доме.

## Основные возможности

- **Автоматический разбор расписания:** Вставка текста в форму или прием через защищенный вебхук. Нераспознанные строки отображаются прозрачно и никогда не удаляются без предупреждения.
- **Разделение на куплеты и повтор припева:** Гимны по номеру разделяются на заглавный слайд, куплеты и повторяющиеся припевы для удобства пения общиной.
- **Визуальный редактор шаблонов (WYSIWYG):** 28 встроенных шаблонов SQLite с интерактивным холстом: перетаскивание, изменение размеров, оформление шрифтов.
- **Один макет для четырех выводов (16:9 широкий):** Единый набор данных управляет файлами PPTX, веб-слайд-шоу, окном проектора и предпросмотром в масштабе 1:1.
- **Режим ведущего для двух мониторов:** Текущий и следующий слайды, лента миниатюр, список служения и независимое окно для вывода на проектор.
- **Затемнение экрана (Blank Screen):** Мгновенное затемнение проектора без потери текущей позиции в презентации (клавиша `B`).
- **Эффекты переходов:** Срез, затухание, растворение и сдвиг, одинаково работающие в браузере и в PowerPoint.
- **Мгновенный вывод библейских стихов:** Отображение стихов Библии (KJV) на проекторе во время проповеди и быстрое скрытие.
- **Объявления общины:** Управление афишами и объявлениями из локального хранилища или разрешенных источников.
- **Внедрение пользовательских шрифтов:** Стандарт ECMA-376 гарантирует точное отображение на любом компьютере с Microsoft PowerPoint.
- **Разграничение прав доступа:** Раздельные учетные записи администратора и оператора, ограничение частоты запросов для защиты от перебора паролей.

## Системные требования

- **Десктопное приложение:** Windows 10/11 64-бит.
- **Сборка из исходного кода:** Go 1.24+ и Node.js 22+. Используется встроенная SQLite, отдельный сервер баз данных не требуется.

## Установка

### Установщик для Windows (Рекомендуется)

Загрузите файл `WorshipDeckSetup.exe` с [официальной страницы релизов](https://github.com/wiradeltaid/worship-deck/releases) и запустите мастер установки.

> **Примечание по Windows SmartScreen:** Поскольку сборка пока не подписана дорогостоящим сертификатом EV, Windows SmartScreen может показать предупреждение. Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.

### Запуск из исходного кода

```bash
git clone https://github.com/wiradeltaid/worship-deck.git
cd worship-deck
npm install
npm run setup
npm run dev
```

`npm run setup` сгенерирует файл `.env`, инициализирует базу данных SQLite, добавит базовые шаблоны и отобразит первоначальный пароль администратора.
