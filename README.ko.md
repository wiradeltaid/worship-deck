# WorshipDeck

> 예배 순서지를 즉시 프레젠테이션 슬라이드로 변환하는 로컬 우선 교회 예배 프레젠테이션 및 스테이징 스위트 — 폰트가 임베딩된 오프라인 PowerPoint (.pptx), 듀얼스크린 프로젝터 콘솔, 로컬 Wi-Fi 스마트폰 리모컨 완비.

교회 예배 환경을 위해 설계되었으며, 슬라이드 템플릿이 하드코딩이 아닌 데이터로 관리되므로 유사한 예배 순서를 운영하는 모든 교회에서 브라우저를 통해 손쉽게 맞춤 조정할 수 있습니다.

## 해결하는 과제

매주 예배 슬라이드를 수작업으로 준비하는 데는 2~4시간이 소요되며, 대부분의 시간은 이미 입력해 둔 찬송가 가사를 다시 타이핑하는 데 낭비됩니다. 예배 직전 찬양이 변경되면 슬라이드를 처음부터 다시 제작해야 하며, 프로그램 설정 노하우도 특정 봉사자 1인에게 의존하기 쉽습니다.

WorshipDeck은 예배 기획자가 작성한 순서지 텍스트(메신저 복사 또는 챗봇 전송)를 입력받아 깔끔하고 정돈된 예배 슬라이드를 자동으로 생성합니다.

```text
순서지 텍스트  →  예배 순서 자동 분석  →  슬라이드 계획 생성  →  ┬→  오프라인 PowerPoint (.pptx)
                                                                ├→  전체화면 웹 슬라이드쇼
                                                                └→  운영자 콘솔 + 회중용 프로젝터
```

찬송가 가사는 번호 조회를 통해 로컬 데이터베이스에서 즉시 인덱싱됩니다. 슬라이드 레이아웃은 관리자가 브라우저에서 SQLite 레지스트리를 통해 직접 편집할 수 있습니다. PowerPoint 파일이 다운로드된 후에는 인터넷 연결이 전혀 필요하지 않으므로 교회의 네트워크에 장애가 발생해도 예배가 원활하게 진행됩니다.

## 주요 기능

- **순서지 자동 파싱:** 웹 폼 붙여넣기 또는 웹훅 연동을 통해 순서지를 자동으로 인식합니다. 인식되지 않은 항목은 누락 없이 투명하게 안내합니다.
- **찬송가 자동 분할 및 후렴구 반복:** 찬송가 번호가 지정되면 제목, 각 절, 반복되는 후렴구로 최적 분할되어 회중이 편안하게 찬양할 수 있습니다.
- **캔버스 기반 템플릿 편집기 (WYSIWYG):** 38종의 내장 템플릿을 드래그 앤 드롭, 크기 조정, 폰트 스타일링, 텍스트 상자 추가 등으로 자유롭게 조정할 수 있습니다.
- **하나의 레이아웃으로 4가지 출력 (16:9 와이드):** 단일 슬라이드 데이터가 파워포인트, 웹 슬라이드쇼, 프로젝터 출력, 실시간 미리보기를 1:1 픽셀 단위로 구동합니다.
- **듀얼스크린 발표자 모드:** 현재/다음 슬라이드 미리보기, 필름스트립, 전체 순서지 목록, 원하는 슬라이드로 즉시 이동 가능한 그리드, 프로젝터 전용 독립 창을 지원합니다.
- **블랙아웃 화면 기능 (Blank Screen):** 슬라이드 진행 위치를 잃지 않고 회중용 프로젝터 화면을 즉시 검게 암전하거나 복원할 수 있습니다(단축키 `B`).
- **다양한 화면 전환 효과:** 컷, 페이드, 디졸브, 푸시 효과가 웹과 파워포인트 양쪽에서 동일하게 적용됩니다.
- **성경 구절 즉시 검색:** 예배 진행 중에도 성경 구절(KJV)을 프로젝터에 즉시 띄우고 지울 수 있습니다.
- **교회 공지 포스터 관리:** 주보 공지사항 포스터를 로컬 업로드 또는 허용된 URL을 통해 관리합니다.
- **사용자 정의 폰트 임베딩:** 전용 폰트 파일을 임베딩하여 다른 PC에서도 깨짐 없이 파워포인트 오프라인 재생이 가능합니다.
- **관리자/운영자 역할 분리:** 계정 분리, 무차별 대입 방지 로그인 제한, 즉시 폐기 가능한 보안 세션을 제공합니다.
- **설정 가능한 순서지 파서 및 폼 레이아웃:** 관리 패널에서 이름이 지정된 파싱 프로필을 작성하고, 코드 변경 없이 서비스 폼의 필드/그룹을 구성할 수 있습니다.
- **미디어 라이브러리:** 특정 템플릿에 종속되지 않는, 재사용 가능한 배경/전단지 이미지 모음입니다.
- **수동 기기 간 동기화** *(실험적 기능 — 실제 두 기기 간 동작은 아직 검증되지 않음)*: 같은 로컬 네트워크에 있는 두 WorshipDeck 인스턴스 간에 서비스, Song Set 항목, 배경, 공지사항을 오퍼레이터가 요청할 때만 주고받습니다. 클라우드 없음, 백그라운드 동기화 없음.

## 시스템 요구사항

- **데스크톱 앱:** Windows 10/11 64비트.
- **소스 빌드:** Go 1.24+ 및 Node.js 22+. 내장 SQLite를 사용하므로 별도의 외부 데이터베이스 서버가 필요하지 않습니다.

## 설치 안내

### Windows 데스크톱 설치 프로그램 (권장)

공식 [GitHub Releases 페이지](https://github.com/wiradeltaid/worship-deck/releases)에서 `WorshipDeckSetup.exe`를 다운로드하여 설치 마법사를 실행하십시오.

> **Windows SmartScreen 안내:** 상용 고비용 EV 코드 서명 인증서가 아직 적용되지 않아 경고가 표시될 수 있습니다. **"추가 정보"**를 클릭한 후 **"실행"**을 누르면 정상 설치됩니다.

### 소스코드에서 직접 실행

```bash
git clone https://github.com/wiradeltaid/worship-deck.git
cd worship-deck
npm install
npm run setup
npm run dev
```

`npm run setup`은 새로운 보안 키가 포함된 `.env` 생성, SQLite 데이터베이스 초기화, 기본 슬라이드 템플릿 등록, 관리자 초기 비밀번호 생성을 자동으로 수행합니다.
